# War3FySnow
Multiplayer Game - Preview  - *An older Unity Project (Multiplayer Online Battle Arena - FPS)*  
  
Dota 2 Character Models are employed, with some modifications, on a small Counter-Strike like Snow map.  
  
  
Some local content has been removed for now. (Server - Client connectivity is currently under development)  

    
Unity Project Source v0.3 -> https://drive.google.com/file/d/1hAFBrSHkU5doA3RLUwn6NTJdPGh0rNTN/view  
  
Unity Project Source v0.1 -> https://drive.google.com/file/d/14TbUB3eYGOMrIxItp6-jkIYo4gtDyY09/view
                     

  
Project status:  
   
 * Simple Multi Thread TCP Server will listen over port 2026 within the Starting Scene
 * Snow Terrain defined  
 * A couple of dota characters with rig and basic animation sources included  
 * Minimal movement and animations employed  
  

Project updates will come, but code snips could be regularly added to github.
